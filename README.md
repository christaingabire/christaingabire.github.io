# Christa Ingabire — Personal Website

This repository contains the source code for my personal website, built with
[Quarto](https://quarto.org/).

The website includes a personal homepage, an about page, a blog, and
computational posts written in Python and R. The Python environment is managed
with `uv`, while the R environment is managed with `renv` so that the
computational analyses can be reproduced on another machine.

## Prerequisites

To build the website locally, install:

- Quarto 1.10 or later (developed with Quarto 1.10.18)
- uv 0.12 or later (developed with uv 0.12.7)
- R 4.6 or later (developed with R 4.6.1)
- Git

Git is required to clone the repository

## Clone the repository

Clone the repository and move into the project directory:

```bash
git clone git@github.com:christaingabire/christaingabire.github.io.git
cd christaingabire.github.io
```

All remaining commands should be run from the **top-level project directory**,
where `_quarto.yml`, `pyproject.toml`, and `renv.lock` are located.

## Set up the Python environment

The Python dependencies and versions are recorded in `pyproject.toml`,
`uv.lock`, and `.python-version`.

Recreate the Python environment with:

```bash
uv sync
```

The local `.venv` directory is generated by `uv` and is not stored in the
repository.

## Set up the R environment

Start R from the top-level project directory:

```bash
R
```

Inside the R console, restore the packages recorded in `renv.lock`:

```r
renv::restore()
```

Then exit R:

```r
q()
```

If prompted to save the workspace image, choose `n`.

## Build the website

From the top-level project directory, render the complete website with:

```bash
uv run quarto render
```

The rendered website is written to:

```text
docs/
```

To preview the website locally, run:

```bash
uv run quarto preview
```

## Data

The computational posts use datasets provided through their respective
packages:

- The Python post uses the Palmer Penguins dataset from the `palmerpenguins`
  Python package
- The R post uses the Gapminder dataset from the `gapminder` R package

The posts do not require API keys or authentication. Internet access is needed
when initially restoring or installing the Python and R package dependencies

## Reproducibility

The Python environment is recorded by:

- `pyproject.toml`
- `uv.lock`
- `.python-version`

The R environment is recorded by:

- `renv.lock`
- `.Rprofile`
- `renv/activate.R`

Local environments such as `.venv/` and `renv/library/` are not committed to
the repository
